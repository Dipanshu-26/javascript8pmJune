Installation Steps for JavaScript and Visual studio code 

Install Node.js (Required for JavaScript practice) 
Step 1: Download 
-------------------
Go to the official download page:  https://nodejs.org/en/download
Download the LTS (Long-Term Support) version. This is the recommended version for most users because it is stable and receives long-term updates.

Step 2: Install  Node.js:
----------------------------
Windows: Run the downloaded .msi installer, accept the license agreement, keep the default installation options, and complete the setup.

macOS: Open the downloaded .pkg installer and follow the installation wizard.

Linux: You can either install using your distribution's package manager or, preferably, use a version manager such as nvm. The official Node.js site provides installation instructions for different distributions.

Double-click .msi → Next → Accept → Install → Finish 

Step 3: Verify Installation 
------------------------------
Open Command Prompt / Terminal: node -v
