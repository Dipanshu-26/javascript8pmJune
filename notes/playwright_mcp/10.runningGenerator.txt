10 . Running the Generator
-------------------------------
The Generator turns a plan scenario into a runnable test.

Switch the chat mode to playwright-test-generator

Use this prompt:
prompt in Copilot Chat — Generator mode

Use scenario 1.1 from specs/saucedemo-login.md.
Context:
    - App under test: https://www.saucedemo.com
    - Credentials: load from tests/data/users.json (users.standard)
    - LoginPage does not exist yet — create it at src/pages/LoginPage.ts
    - InventoryPage does not exist yet — create it at src/pages/InventoryPage.ts
Rules:
    - Import test from src/fixtures/base.ts, NOT from @playwright/test
    - Both page objects must extend BasePage
    - Locators: getByRole > getByLabel > getByTestId. No CSS, no XPath.
    - No page.waitForTimeout
    - Tag the test with @smoke @critical

Task:
    1. Create the two page objects
    2. Generate the test at tests/auth/standard-login.spec.ts
    3. Run the test and confirm it passes
    4. Report the result

The Generator will:
    1. Read the plan file
    2. Open a Chromium browser to verify locators
    3. Create src/pages/LoginPage.ts (asks before creating)
    4. Create src/pages/InventoryPage.ts (asks before creating)
    5. Write the spec file
    6. Run the test
    7. Iterate until it passes

Note for you : Approve each file creation when prompted, or enable auto-approval in the chat settings.

What to verify after generation
-----------------------------------
Open each generated file and check:
    - Imports come from ../../src/fixtures/base, not @playwright/test
    - Page objects extend BasePage
    - All locators use getByRole, getByLabel, or getByTestId
    - No CSS selectors, no XPath, no page.waitForTimeout
    - No expect() calls inside page objects
    - Test title has the tags applied
If any of these are violated, do not accept the code as-is. This is the review skill.
